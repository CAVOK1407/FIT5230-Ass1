## 0. 一句话结论

论文最大的三块短板是：**跨检测器迁移不稳（尤其是 CLIP 语义检测器）**、**完全没测后处理鲁棒性（JPEG/缩放）**、**优化目标和最终输出路径不一致（代码事实）**。
4 天内最划算的 M2 组合是：

1. **代理检测器集成 + 动量**（提升迁移，改动最小，收益最确定）
2. **把 LAO 的攻击损失算在最终 Control-VAE 解码路径上**（修正"优化的图 ≠ 输出的图"）
3. **margin 损失 + LPIPS 约束**（顺手加，几行代码）
4. **JPEG / 缩放鲁棒性评测**（论文空白；先评测，时间够再把 EOT 放进 LAO）
5. **评测升级**：≥100 张图、leave-one-out 迁移、公开权重的 UnivFD / NPR 当真正的黑盒目标、报告真实图误报率和 AUC

其余方向（重训 Control-VAE、黑盒查询、水印、蒸馏加速）留给 M3 / M4。

## 4. 论文弱点 → 攻击侧改进方向（全景）

先记住论文的三块关键数据：
- Table 2：迁移到 UniDetection（CLIP 特征 + 线性探针）时，用 E/R/D/S 做代理的 ASR 只有 **46.38 / 61.13 / 18.63 / 27.75%**，而对 DIRE/GFF/LGrad/RECCE 平均 87–94%。
- Table 5：加了 Control-VAE 之后白盒 ASR 从 100 掉到 97–98%（频谱对齐目标和"骗过特定检测器"目标不完全一致）。
- Table 7：真实照片只经过 SD 的 VAE 重建一遍，被判"真实"的概率从 100% 掉到 78.6–92.3%（结构性弱点：所有输出都必经 SD 解码器）。

代码事实（固定 commit a156fb0）：LAO 循环里用**普通 VAE** 解码后算攻击损失，循环结束后才用 **Control-VAE** 生成最终输出；LPIPS/L1 算了但没进目标函数；代码默认 10 次 LAO，论文写 5 次。

可行性标记：★★★ = 4 天内能做完并出数；★★ = 时间允许可做；★ = 只做评测/小消融；✗ = 留到 M3/M4。

| # | 论文弱点 | 改进方向（Dark） | 预期收益 | 难度 / 算力 | M2 |
|---|---|---|---|---|---|
| D1 | 只用单个代理检测器，迁移不稳（Table 2 波动 18–61%） | **多代理集成**：LAO 损失改为 E/R/D/S 中若干个的平均或随机加权；加**动量（MI）**和潜变量输入多样性（DI，随机缩放/平移后再解码） | 迁移 ASR 明显提升（像素域经验 +10–30 点） | 低。四个模型代码已加载；显存 A100 40 GB 够 | ★★★ |
| D2 | 优化的图和输出的图不是同一张（普通 VAE vs Control-VAE） | **在最终 Control-VAE 解码路径上算损失**（现计划的改动 A）；先用 3.7/3.8 统计"普通 VAE 能逃逸、最终输出又被抓回"的比例 | 消除"回退"样本；提高最终输出的 ASR | 低–中。梯度要穿过 Control-VAE 解码器 | ★★★ |
| D3 | 只报固定阈值下的 ASR，不报 AUC；样本可能只是刚过边界 | **margin / CW 式损失**：把"真实"类 logit 推到高置信；或过界后继续优化 k 步。评测报 score 分布、AUC、不同阈值下 ASR | 抗阈值调整，攻击"余量"更大 | 低 | ★★★ |
| D4 | **完全没测后处理鲁棒性**（论文全部在无损 PNG 上） | 先做评测：JPEG q=90/75、缩放 0.5×、重采样；再把 **EOT 放进 LAO**（可微 JPEG + 随机缩放/模糊），期望值上优化 | 从"实验室有效"到"传播后仍有效" | 评测低；EOT 进 LAO 中（要可微 JPEG，显存翻倍） | 评测 ★★★ / EOT ★★ |
| D5 | **语义特征检测器盲区**（UniDetection 最低 18.63%） | (a) 加 **CLIP 线性探针代理**（自己用真/假图训一个，别用目标同款权重）；(b) 加 **特征对齐项**：把输出的 CLIP/DINOv2 特征拉向真实图特征均值；用公开 UnivFD 权重当 held-out 黑盒目标 | 补上论文最弱一环，故事最好讲 | 中。需要真/假各 1–2k 张训探针；CLIP ViT-L/14 显存 | ★★ |
| D6 | 只用 PSNR/SSIM 说"人眼看不出"，代码里 LPIPS 算了不用 | 把 **LPIPS 约束**加进 LAO 目标（或逐像素自适应预算）；报告 LPIPS/DISTS | 同等画质下换更大攻击空间；防止 D1/D3 把画质打坏 | 低 | ★★ |
| D7 | 梯度链只有 2 个扩散步、5–10 次迭代，无消融 | 在 A100 上做 diffusion steps ∈ {2,3,5} × iterations ∈ {5,10,20} 的小消融；显存不够用 gradient checkpointing | 可能有未挖掘的性能余量 | 低–中，主要是耗时 | ★ |
| D8 | NPL 只对齐幅度谱的**均值**：无相位、无分布、无局部谱 | 重训 Control-VAE：分布匹配（sliced-Wasserstein / MMD / 频域判别器）+ 相位项 + 分块局部谱 | 抗更强的频域检测器 | 高。Control-VAE 训练约 1–2 天 A100 + 真实图训练集 | ✗ → M3 |
| D9 | **结构性弱点**：输出必经 SD 解码器，带"VAE 重建指纹"（Table 7） | (a) 自己训一个"是否经过 VAE 重建"的检测器（真图 vs VAE(真图)），先当评测，再当额外代理加进 LAO；(b) 输出端"残差移植" x' = x0 + (D(ẑ) − D(E(x0)))，避开整图重建痕迹（会保留原图指纹，要实验） | 预判 Light 队最可能的杀手锏 | 中。(a) 的数据零成本，ResNet-18 训几十分钟 | ★（先做 (a) 评测） |
| D10 | 纯迁移攻击，没有查询反馈 | 迁移后用少量查询做校准（score-based，Square / SimBA 在潜空间） | 对陌生检测器有兜底 | 中 | ✗ → 与 Light 队互动时用（M3） |
| D11 | 忽略水印 / 内容凭证（Tree-Ring、Stable Signature、C2PA） | 测 StealthDiffusion 流程是否顺手洗掉水印 | 全新应用面，很适合 M4 的"无约束增强" | 中–高，要先生成带水印的图 | ✗ → M4 |
| D12 | 官方只在 224×224 上攻击，真实图更大 | 512 攻击 + 检测器分辨率对齐的频谱损失（现有 RQ4 代码） | 更贴近真实 | 中，代码已有 | ★（低优先） |
| D13 | 没报计算开销 | 报单图耗时、显存；长期可做一步蒸馏 | 可行性判断 | 报数字低；蒸馏高 | 只报数字 |
| D14 | 每子集 100 张、无置信区间、无真实图误报率 | ≥100 张、按生成器分组、95% 置信区间、真实图 FPR、条件 ASR 的分母 | 直接拿 technical depth 分 | 低 | ★★★ |

关于讲义提出的三个"可立项选题"（重建痕迹检测器、水印存活率、分布匹配版频谱对齐）：前两个是防守视角或 M4 素材，第三个是 D8，都不适合放进 4 天的 M2。

## 5. 推荐的 M2 最小可行方案（4 天）

### 5.1 数据方案（先解决，不然什么都跑不了）

GenImage 分卷太大，4 天内别碰。替代方案：
- **生成图**：在 A100 上用 diffusers 跑 SD 1.5（或 SD 1.4）生成 200 张 512×512，prompt 用 "a photo of a {类名}"，类名取 Imagenette 的 10 个 ImageNet 类。这和 GenImage 的 SD 子集构造方式接近，官方检测器应能识别（跑前先验证 clean 检测率）。10 分钟以内。
- **真实图**：Imagenette（ImageNet 公开子集，可直接下载）取 200 张 val 图。
- 攻击前先在开发集（各 30 张）验证四个官方检测器的极性（官方 0=AI，1=真实）和 clean 准确率，再冻结阈值；测试集各 100 张不参与调参。
- 攻击用的 SD 2.1-base 和生成输入图的 SD 1.5 分开记录。

### 5.2 实验序列（全部在 A100，每张图都保存 PNG 并重新读入评测）

| 编号 | 实验 | 说明 |
|---|---|---|
| E0 | **B00 官方基线**：代理 E，10 次 LAO，100 张 | 报 R/D/S 迁移 + UnivFD/NPR（公开权重）held-out + PSNR/SSIM/LPIPS + 单图耗时。同时保存普通 VAE 候选，统计回退比例（D2 的动机） |
| E1 | **+ 集成代理（D1）**：leave-one-out，用 3 个代理攻击、第 4 个测迁移 | 这是主要的"改进"证据；对四种留出组合各跑一次 |
| E2 | **+ 最终路径损失（D2）** | 与 E1 用相同图、相同种子、相同迭代次数 |
| E3 | **+ margin 损失 + LPIPS 约束（D3/D6）** | 报 AUC 和不同阈值下 ASR，证明"余量" |
| E4 | **鲁棒性评测（D4）**：对 E0–E3 的输出统一做 JPEG q=75 / 缩放 0.5× 后再测 | 原图和攻击图用相同处理再定分母 |
