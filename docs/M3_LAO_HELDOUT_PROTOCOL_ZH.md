# LAO 新种子验证与严格预算 PGD 对照

协议冻结时间：2026-10-18T15:34:22.526774+08:00

## 研究问题与范围

在未参与本项目调参的新 SD1.5 图片上，既有残差锚点 LAO 的作用能否重现？导出文件限制为相同 L∞ 预算后，它是否优于纯像素 PGD？本轮不重新训练权重，不用新数据选择参数，不改动第三轮已冻结的 LAO 优化算法。

这里的“独立作用”“同预算竞争力”“原混合流程中的主导性”是不同结论。关闭 PGD 只保证优化变量独立，不能凭此证明 LAO 胜过 PGD。本轮也没有混合流程的因子消融，因此不直接证明旧完整流程中的主导性。

## 新数据

50 张新 SD1.5 图，原10个类别各5张，种子5231000–5231049。使用原清单的精确提示词，30步、CFG7.5、512×512生成，再以LANCZOS缩放为224×224。模型版本固定为451f4fe16113bff5a5d2269ed5ad43b0592e9a14，PNDM调度器。生成使用float32、MPS、逐图CPU随机生成器和attention slicing；这些运行条件记录在生成计划中。

50张真实图来自现有Imagenette原始验证文件：按实际类别目录及文件名排序，排除旧110张来源及像素内容，每类取前5张。不得用错误的旧parachute目录名构造路径。

生成前写入全部prompt/seed计划；生成后以canonical RGB224内容哈希排除旧136张生成图、110张真实图和本批次内部重复，不按检测分数或视觉偏好筛选。重复、损坏或缺失导致停止核查，不私自换图。旧实验结果中的origin内容也已独立审核，未发现上述旧生成集合之外的额外输入。

这批是同生成模型、同语义类别的新种子验证，不代表新模型/新语义泛化，也不满足旧论文每格250个caught样本的规则。

## 固定配置与输出预算

LAO：第三轮残差锚点公式、clean encoding/clean control、跳连系数0.5、E为唯一目标、margin κ=3、LPIPS权重1、10次AdamW更新、lr0.01、weight_decay0、STE量化、seed42、无DI/EOT，模型权重冻结。额外独立运行相同结构的0步基线。

预算：以参与检测的原始224×224 RGB uint8图为中心，所有主比较输出必须满足整数 `max(abs(output-original)) <= 8`，即 L∞≤8/255，零容差。使用int16计算与裁剪，输出直接保存为uint8，再重新读取PNG硬校验。不会围绕normalize/denormalize回转后的浮点图建立预算。

| 组 | 设置 | 是否用于严格预算主比较 |
|---|---|---|
| RAW_RECON | 独立零步残差锚点重建 | 否，仅机制诊断 |
| RAW_LAO | 冻结的10步残差锚点LAO | 否，仅机制诊断 |
| RECON8 | RAW_RECON导出图投影到整数±8 | 是，重建控制 |
| LAO8 | RAW_LAO导出图投影到整数±8 | 是，主方法 |
| PGD10 | 干净图起步；10步，步长2/255，margin κ3+LPIPS1，量化感知；最终迭代 | 是，短程对照 |
| PGD40 | 40步×3起点（干净+2个固定种子随机起点）；步长2/255，最大化AI标签CE；仅按E分数选全部迭代/起点中的最佳保存候选 | 是，强参考 |

PGD随机种子20261018，逐图派生固定随机流。所有PGD变量都在像素空间，无diffusion/latent优化。

**方法差别必须保留：**LAO优化时没有看到导出后的预算投影；PGD在预算内优化。LAO8检验的是既有冻结方案在输出约束下剩余的效果，不是“最优约束LAO”。PGD10共享margin+LPIPS形式，但其LPIPS在保存前向图上计算，冻结LAO的LPIPS使用原始decoder值；不得声称目标函数的所有细节完全相同。PGD40还使用更充分的计算和不同CE目标，是独立强参考。10步LAO与10步PGD不等算力，分别报告实测耗时。

RAW_LAO的reset latent图必须逐字节匹配独立RAW_RECON；对应投影图也必须匹配。该检查不通过则先调查实现，不发布归因结论。

## 评估与预先固定的结论标准

主条件：重读实际PNG，无额外变换。预算与画质都针对保存文件测量。探索性画质门槛沿用PSNR≥30dB、LPIPS≤0.15；不等于人工语义盲审。

- 同一检测器/条件下，“原图被检出”的集合对所有方法一致；保留全部50张图，不删掉失败或画质不合格图。另报无条件逃逸率、真实图FPR。
- 主终点：E/none上LAO8相对PGD40的**画质合格条件ASR配对差**。按源图做10,000次配对bootstrap（seed20261018），报告95%区间及discordant pairs的精确McNemar检验。
- 只有区间下界>0且双侧p<0.05才支持本协议下的优越性。另预设5个百分点的非劣界。为避免全体配对结果相同时bootstrap退化成[0,0]，对LAO-only与PGD-only两类不一致概率分别构造97.5% Clopper–Pearson区间，再作差获得Bonferroni保守95%配对差区间；仅其下界>−0.05才支持非劣性。样本小，统计功效可能不足。
- PGD10为次要对照；LAO8相对RECON8的新增、丢失及净成功用于归因。
- R/D/S迁移和JPEG75、resize05为描述性次要结果，不在看完结果后改选主终点、不把模型数当独立样本量。变换后的文件不另宣称仍满足原始8/255预算。
- 原始未投影LAO的结果只回答结构能否在新样本上重现，不能混入严格预算排名。

若LAO8落后，本轮只能得出冻结方案经导出约束后的竞争力不足；不能据此否定一切latent优化理论。若要把预算放进LAO优化循环，需要另立约束方法、先在旧开发集定型，再使用另一批新验证数据。
